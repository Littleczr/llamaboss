LlamaBoss findings 2-4 patch (incremental)
Base required: the Finding 1 launch-generation guard patch.

Implemented
-----------
2. Shared lifecycle adjudication
   - ModelService alone validates ready/error generations, performs the
     no-Jinja retry decision, calls NotifyServerReady, and writes shared
     readiness/active target state.
   - Frames receive accepted lifecycle events for UI/deferred work only.

3. Per-window conversation model preference
   - Loading/browsing a saved conversation no longer changes AppState's active
     target or shared readiness.
   - Conversation saves and frame-owned message labels use the frame's model.
   - The first Send requests a shared local switch only when that conversation
     actually needs it.
   - Saved remote wire-model IDs are restored only when the endpoint is the
     active endpoint, the last matching selection, or a unique configured
     match. Ambiguous provider matches are never guessed.

4. Consistent remote/local state propagation
   - Versioned ModelService state events cover loading, ready, error, remote
     synthesized-ready, stopped, and late-joining windows.
   - Remote activation and local starts route through ModelService.
   - Existing and newly opened frames project the shared target through their
     own conversation preference.
   - Context/KV changes while remote is active no longer try to launch a remote
     wire-model ID as a local GGUF.
